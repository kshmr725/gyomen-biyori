## 1. 產品定位 (Product Positioning)

**魚麵日和** 不是簡單的拉麵抽籤玩具或 MVP Demo 頁面，其核心定位為：

> **Taipei Ramen Knowledge Base（台北拉麵資料庫與探索平台）**

### 核心目標
1. **台北最完整、最可信、最好探索的拉麵資料庫**：提供全台北最有結構化、經過查證驗證的拉麵店家資料。
2. **可持續成長的產品架構**：從 MVP 30–50 間 A 級名店開始，逐步擴充至百家資料庫與社群生態，非一次性專案。
3. **專屬美食指南**：以小魚與團隊的編輯品味為基底，結合數據計算與精準過濾，給予使用者最值得信任的答案。

---

## 2. 產品核心價值 (Core Value Proposition)

解決使用者在「尋找台北拉麵」時的資訊碎片化與選擇困難：

* **找今天想吃的拉麵**：透過條件問答（步行時間、預算、排隊耐心、交通）直接計算最佳推薦。
* **探索沒吃過的新店**：提供高品味的地圖與清單瀏覽，發掘優質新拉麵店。
* **比較不同湯頭與特色**：結構化標記豚骨、雞白湯、醬油、煮干、沾麵、限定款等湯頭分類。
* **找符合特殊需求的店**：宵夜、一人友善、信用卡/LINE Pay支付、停車便利、約會環境。
* **信任魚麵整理過的資訊**：每筆資料皆標註可信來源與更新日期，免去重複開啟 Google Maps、Threads 或 PTT 翻找貼文的困擾。

## 3. MVP（V2 階段）範疇定義

### 3.1 核心 UX 頁面與流程
1. **Wizard 推薦問答**：
   - 選擇地點（熱門捷運站 / GPS 定位 / 歷史選取紀錄）
   - 選擇交通與喜好（純步行 / 捷運 / 機車、預算、排隊耐心、新店優先）
   - 計算並給予唯一首選推薦卡，下方附帶 Leaflet CARTO Positron 低彩度互動地圖與候選 Deck。
2. **Explore 探索地圖與清單**：
   - 雙欄/雙頁切換（清單 + CARTO Positron 幾何點標誌地圖）。
   - 點選清單自動聚焦地圖；點選地圖 Marker 自動凸顯店家卡片。
3. **Shop Detail 店家詳細頁**：
   - 店家基本資訊、營業時間狀態、當前時段預估排隊層級、招牌菜單與圖集、編輯短評與查證資料來源列表。

### 3.2 初始資料量與品質
- **數量**：精選 30–50 間台北 A 級拉麵店家。
- **品質要求**：每一間店家資料均需 100% 人工或官方管道完整驗證（標示 `dataQuality: "verified"`）。

### 3.3 CMS（內容管理系統）需求
無需修改程式碼，即可透過管理後台或微服務完成：
- 新增/編輯店家基本資料與分店
- 更新店家照片集與菜單價格
- 更新營業時間與臨時休業公告
- 更新時段排隊預估模型 (Queue level)
- 更新小魚編輯推薦語與湯頭 Tag

## 4. UX 設計原則 (UX Principles)

所有新功能與畫面修改必須嚴格遵守以下五大原則：

1. **Mobile First**：手機瀏覽體驗優先，操作按鈕適應單手點擊區域（Min height 44px），避免水平溢出。
2. **不增加操作步驟**：地點選取後自動前進下一題，移除重複的「確認」按鈕。
3. **不先顯示地圖**：在完成篩選條件前（Step 0–5），DOM 中完全不載入 Leaflet Map，減少效能負擔與畫面雜訊。
4. **不一次塞大量資訊**：資訊分層呈現（視覺卡片 → 標籤 → 展開詳細菜單）。
5. **推薦永遠優先於地圖**：計算結果頁中，最高匹配 Recommendation Card 恆置於最上方，地圖作為輔助工具放置於下方或右側。

## 5. 魚麵分 (Gyomen Score) 規格定義

魚麵分（Gyomen Score）為平台專屬的客觀+編輯綜合指標（評分演算法將於 V3 實現，本階段僅定規格與維度）：

### 評分維度 (Rating Dimensions)
1. **湯頭 (Broth)**：深度、鹹度平衡、香氣與濃厚度。
2. **麵體 (Noodles)**：硬度選配、湯汁吸附力、嚼勁。
3. **叉燒 (Chashu)**：舒肥/炙燒技術、肉質鮮嫩度、厚度與份量。
4. **配料 (Toppings)**：溏心蛋、筍乾、紫洋蔥、海苔之整體搭配。
5. **穩定度 (Consistency)**：不同時段/不同師父出餐的品質穩定度。
6. **CP 值 (Value for Money)**：基本款價格與整體份量/免費加麵優惠之比例。
7. **值得排隊度 (Queue Worthiness)**：排隊時間與美味體驗的最終對價感。
8. **回訪率 (Revisit Rate)**：愛好者頻繁回訪之意願。
9. **編輯推薦 (Editorial Rec)**：小魚與團隊之獨家品味加分。

*註：權重配置與演算法模型將於 V3 設計，不提前硬編碼於代碼中。*

## 6. 搜尋與多維度過濾規格 (Search & Filter Specs)

支援以下條件單選或自由組合過濾：

- **地理距離/交通**：捷運站距離（步行 5/10/15 分鐘內）、當前 GPS 距離。
- **預算區間**：平價 (NT$250內)、標準 (NT$350內)、豪華/無限制。
- **湯頭風味**：豚骨、雞白湯、醬油、鹽味、味噌、煮干/魚介、蝦湯、辛辣、限定/獨創。
- **即時狀態**：營業中 (Open Now)、免排隊 (No Queue)、排隊 30 分內。
- **時段需求**：宵夜拉麵 (21:00 後營業)、午餐不休息。
- **支付與設施**：多元支付（信用卡 / LINE Pay / 街口）、周邊停車場、一人友善 (單人隔板/吧台)、約會質感、親子友善。
- **探索屬性**：未造訪過新店、高 CP 值名店。
